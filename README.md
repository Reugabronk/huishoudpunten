# Huishoudpunten

Webapp om huishoudelijke taken af te vinken en er punten mee te verdienen. Bedoeld voor twee personen op één tablet.

- Weekstand met een kroontje voor wie voorop loopt; elke maandag begint een nieuwe week.
- Oude weken blijven bewaard en zijn terug te kijken met grafieken per dag en per week.
- Taken, punten en namen zijn aan te passen in Beheer (met pincode).
- Alle gegevens staan lokaal in de browser van het apparaat. Via Beheer kun je een back-up downloaden en op een ander apparaat terugzetten.

De hele app is één bestand: `index.html`. Hosten kan met GitHub Pages (Settings → Pages → Deploy from a branch → `main`).
